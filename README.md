# svcsvc

ActiveX-компонент (`Svcsvc.Service`) с полезными функциями для 1С:Предприятие 7.7 и скриптов:
быстрый отбор и фильтрация значений (`FilterValue`), выбор из списка или дерева, всплывающее меню,
диалоги выбора файла и папки, перекодировка ANSI/OEM и другие.

Автор: Александр Орефков. Доработки: kms, metaeditor, ADirks.
Полное описание методов и история версий — в [svcsvc/readme.txt](svcsvc/readme.txt) (кодировка CP1251).

## Изменения в этой версии

- **Работа на нескольких мониторах.** Окно `FilterValue` вписывалось в экран по размерам
  только основного монитора (`SM_CXFULLSCREEN` / `SM_CYFULLSCREEN`). Если форма 1С стояла
  на втором мониторе справа или снизу, окно уезжало к правому краю основного монитора.
  Теперь используется рабочая область того монитора, где показывается окно
  (`MonitorFromPoint` / `MonitorFromWindow` + `GetMonitorInfo`).

## Установка

1. Скопируйте `svcsvc.dll`, например, в `1Cv77\BIN\config\system\`.
2. Зарегистрируйте из 32-битной консоли администратора:
   ```
   C:\Windows\SysWOW64\regsvr32.exe "<путь>\svcsvc.dll"
   ```
   Если DLL уже зарегистрирована по этому пути, достаточно заменить файл (при закрытой 1С).

Нужен Visual C++ 2005 Redistributable (x86) с MFC: DLL собрана с MFC80 и MSVCR80.

## Сборка

Нужна Visual Studio 2005. Запустите `svcsvc\build.cmd`: он соберёт `svcsvc\ReleaseMinDependency\svcsvc.dll`
без регистрации в системе. Можно также собрать через `svcsvc.sln`, но в проекте есть шаг сборки,
который вызывает `regsvr32` и регистрирует собранную DLL.

Исходники хранятся в CP1251 с CRLF.
